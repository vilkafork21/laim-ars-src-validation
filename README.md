# laim-ars-src-validation

Source-нода для `laim-ars-env-validation-uf` и `laim-mart-report-batch`.
Упаковывает единое ядро `data/laim-ars-validation` в детерминированный
`tar.gz`, возвращает base64 и SHA-256. Одинаковые исходники дают одинаковый
checksum; это позволяет однозначно связать отчёт с версией расчёта.

Выходы подключаются парой:

- `codebase_validation → received_codebase`;
- `checksum_validation → received_checksum`.

Ноду нельзя обновлять отдельно от env-ноды, если изменился контракт запуска
или состав результата `validation.main`.

Текущее ядро использует относительные допуски с округлением вверх. K2 считает
максимальное число нарушивших спанов по одному обязательному атрибуту, K3 —
число уникальных трейсов с хотя бы одним разошедшимся инвариантом. Колонки вне
спецификации сохраняются в отчёте, но не понижают K1.
